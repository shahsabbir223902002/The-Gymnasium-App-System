# 🏋️ Gymnasium App System

The **Gymnasium App System** is a modern Android-based fitness management application designed to provide gym services and fitness information in one convenient platform. Users can explore membership plans, trainers, classes, and gym facilities, book classes, make online payments, calculate BMI, and manage their fitness profiles.

---

## 🚀 Abstract

The Gymnasium App System is an Android application developed to make gym services more convenient, accessible, and user-friendly. The application provides features such as user authentication, class booking, membership management, online payment, BMI calculation, trainer information, fitness facilities, and notifications.

The app features a modern dark-themed interface with vibrant orange accents to provide an engaging fitness experience.

---

## 📌 Problem Statement

Traditional gym management and services can involve several difficulties, such as:

- Difficulty finding class schedules and available slots
- Manual class booking and cancellation
- Limited access to membership information
- Difficulty tracking fitness assessments
- Lack of centralized trainer and facility information
- Time-consuming membership and payment management
